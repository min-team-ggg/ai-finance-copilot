# AI-Powered Finance Copilot

An intelligent financial assistant that analyzes spending behavior, provides predictions, and offers conversational financial guidance.

## Features

- 🤖 AI Chat Assistant - Ask questions about your finances
- 📊 Smart Spending Insights - Detect patterns and trends
- 💯 Financial Health Score - Multi-factor assessment (0-100)
- 🔮 Expense Prediction - Forecast upcoming expenses
- ⚠️ Smart Budget Warnings - Alert before overspending
- 💰 Saving Opportunities - Personalized recommendations
- 📈 Weekly Reports - Automated financial summaries

## Architecture

- **Frontend:** React
- **Backend:** Node.js/Express
- **Database:** SQLite (dev), PostgreSQL (production)
- **AI:** OpenAI API for intelligent analysis
